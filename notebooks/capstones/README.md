## C1 · 캡스톤 1: PageRank (Capstone 1: PageRank as a Markov Chain)

- 파일: [C1_pagerank.ipynb](C1_pagerank.ipynb) · 예상 120분 · 선수: 01d, 01e, 01f, 01c, 01r, 00b

**프로젝트 브리프.** 7개 노드짜리 작은 웹 그래프를 마르코프 사슬로 모델링하여 PageRank를 구하고, damping $d$·매달린(dangling) 노드·랭크 싱크가 정상분포와 수렴 속도에 미치는 영향을 정량화한다.

**합격 기준 (이 그림/숫자가 나오면 성공).** (1) $\pi(0.85) = [0.10333, 0.05585, 0.07168, 0.05585, 0.34827, 0.32261, 0.04240]$이 세 가지 방법(선형계·고유벡터·거듭제곱)과 spkit `pagerank`에서 $10^{-10}$ 이내로 일치; (2) 거듭제곱 반복의 $L^1$ 오차가 반로그 그림에서 기울기 $\log d$의 직선(비율 0.85)을 따르고, $|\lambda_2(G)| = d = 0.85$가 수치로 확인; (3) 랜덤 서퍼 20,000명(FAST 2,000명)의 60걸음 후 위치 분포가 모든 노드에서 $\pi$와 4 SE 이내; (4) $d\to 1$에서 질량이 {4,5}로 몰리고($[0,0,0,0,0.5,0.5,0]$), $d\to 0$에서 균등으로 가는 민감도 그림; (5) 매달린 노드를 고치지 않으면 총질량이 300회 반복 후 $6.8\times 10^{-5}$로 새어 나가는 것을 재현.

**재사용 노트북.** 01d(정상분포 세 가지 방법), 01e(수렴 정리·TV 거리·$\lambda_2$), 01f(가역성은 아니지만 사슬 설계 관점), 01c(기본행렬로 도달시간), 00b(MC 오차).

**단계.** Task 1 그래프→행렬, Task 2 정상분포 세 방법, Task 3 거듭제곱 반복과 스펙트럼, Task 4 랜덤 서퍼 MC, Task 5 민감도·개인화·누수 실험.

## C2 · 캡스톤 2: 대기행렬 설계 (Capstone 2: Designing a Service System with Erlang C and M/G/c Simulation)

- 파일: [C2_queue_design.ipynb](C2_queue_design.ipynb) · 예상 120분 · 선수: 03c, 03d, 03e, 03r, 02a, 00b, 00c

**프로젝트 브리프.** 콜센터(또는 창구) 설계: 도착률 $\lambda = 40$/시간(푸아송), 평균 서비스 5분($\mu = 12$/시간, 제공 부하 $a = \lambda/\mu = 10/3$ Erlang). SLA: '1분 넘게 기다리는 고객 비율 $\le 10\%$', 즉 $P(W_q > 1\text{분}) \le 0.10$. 비용: 서버 시간당 30, 고객 대기 시간당 60(고객·시간당). 과제: (i) Erlang C로 SLA를 만족하는 최소 서버 수 $c^*$를 정하고, (ii) 비용 곡선과 대조하고, (iii) 서비스가 지수분포가 아닐 때(결정적 $c_s^2=0$, 초지수 $c_s^2=4$) 같은 $c$가 여전히 SLA를 지키는지 M/G/c 시뮬레이션으로 검사한다.

**합격 기준 (이 그림/숫자가 나오면 성공).** (1) Erlang C 표: $c=5$에서 $P(W_q>1\text{분}) = 0.2341$(위반), $c=6$에서 $0.0870$(만족) → $c^*=6$; $P(\text{wait}) = 0.1482$, $W_q = 0.278$분, $L = 3.519$; (2) 비용 곡선의 최소는 $c=5$(189.2/h)이지만 실현가능해(SLA)에서는 $c=6$(191.1/h); (3) M/M/c 시뮬레이션(Kiefer–Wolfowitz 재귀, 200회 반복 × 20,000 고객)이 $c=5,6,7$ 모두에서 $P(W_q>1\text{분})$·$P(W_q>0)$·$W_q$를 Erlang C와 4 SE 이내로 재현; Gillespie CTMC(03c)로 $L$과 $P(N\ge6)$도 재현; (4) M/G/1 검증: $\rho=0.8$에서 $W_q$ = 10분(D)/20분(M)/50분(H2, $c_s^2=4$) — Pollaczek–Khinchine와 4 SE 이내; (5) 강건성 그림: $c=6$에서 결정적 서비스는 0.066(여유), $c_s^2=4$ 초지수는 $0.1007\pm0.0007$로 SLA를 아슬아슬하게 위반 → 7대 필요(0.034).

**재사용 노트북.** 03c(출생–사망 정상분포·Gillespie 시간평균), 03d(M/M/1·리틀·PASTA), 03e(Erlang C/B), 02a(경쟁하는 시계, 지수합), 00b(SE·반복 실험), 00c(기하합의 지수분포).

**단계.** Task 1 Erlang C 표와 $c^*$, Task 2 비용 곡선, Task 3 M/M/c 두 가지 시뮬레이터 검증, Task 4 M/G/1 P–K 검증, Task 5 M/G/c 강건성, Task 6 설계 메모.

## C3 · 캡스톤 3: MCMC와 이징 모형 (Capstone 3: MCMC and the 2D Ising Model)

- 파일: [C3_mcmc_ising.ipynb](C3_mcmc_ising.ipynb) · 예상 150분 · 선수: 01f, 01e, 05a, 01d, 05r, 00b

**프로젝트 브리프.** 2차원 이징 모형($J=1$, $k_B=1$, 외부장 0, 주기 경계)을 메트로폴리스 MCMC로 표본화하여 (i) 자화 $\langle|m|\rangle(T)$ 곡선과 Onsager 임계온도 $T_c = 2/\ln(1+\sqrt2) = 2.26919$를 재현하고, (ii) 세부 균형·정상분포를 완전 열거가 가능한 $3\times3$(512 상태)에서 정확히 검증하며(01f), (iii) 스펙트럴 갭과 TV 거리로 혼합 속도를 보고(01e), (iv) 자기상관 시간 $\tau_{int}$의 임계 감속(critical slowing down)을 측정한다(05a의 정상열 분산).

**합격 기준 (이 그림/숫자가 나오면 성공).** (1) $3\times3$ 메트로폴리스 전이행렬 $P$(spkit `metropolis_chain`)가 볼츠만 분포를 정상분포로 갖고 세부 균형을 $10^{-12}$ 이내로 만족; $T_c$에서 $|\lambda_2| = 0.996348$(홀 모드), $|\lambda_3| = 0.944340$(짝 모드); (2) 균등 초기분포에서 TV 거리가 $|\lambda_3|^n$을 따라 $n=300$에 $3.6\times10^{-8}$까지 떨어지지만 all-up 초기상태에서는 $n=300$에도 0.176(느린 홀 모드) — 두 곡선이 한 그림에; (3) `simulate_chain`으로 만든 $3\times3$ 표본의 $\langle|m|\rangle$, $\langle e\rangle$, $\langle m^2\rangle$이 정확값 0.87107, $-1.61125$, 0.80943과 4 SE 이내; (4) 체커보드 메트로폴리스 샘플러의 $4\times4$ 결과가 완전 열거 정확값($T_c$: $\langle|m|\rangle = 0.84386$, $\langle e\rangle = -1.56562$; $T=2.5$: 0.76471, $-1.37912$)과 4 SE 이내; (5) $L=16$/$32$ 자화 곡선이 $T<2.1$에서 Onsager 곡선과 겹치고 $T_c$ 근처에서 급락하며($L=16$: $T_c$에서 0.72, $L=32$: 0.64), $\tau_{int}(|m|)$이 $T_c$ 근방에서 봉우리를 이루고 $L$과 함께 커진다($L=8$: ≈3, 16: ≈9, 32: ≈40 sweep).

**재사용 노트북.** 01f(메트로폴리스·세부 균형·`metropolis_chain`), 01e(TV 거리·$\lambda_2$·수렴 정리), 05a(정상열의 분산과 조건부 기대), 01d(`stationary`), 00b(SE·반복).

**단계.** Task 1 3×3 정확 사슬, Task 2 3×3 MC 검증, Task 3 체커보드 샘플러 4×4 검증, Task 4 자화 곡선, Task 5 자기상관과 임계 감속.

## C4 · 캡스톤 4: 옵션 가격 결정 (Capstone 4: Monte Carlo Option Pricing with Variance Reduction)

- 파일: [C4_option_pricing.ipynb](C4_option_pricing.ipynb) · 예상 150분 · 선수: 07e, 07c, 00b, 06c, 06e, 07d

**프로젝트 브리프.** 블랙–숄즈 세계($S_0=100$, $K=100$, $r=0.05$, $\sigma=0.2$, $T=1$, 위험중립 GBM $dS = rS\,dt + \sigma S\,dW$)에서 유러피언 콜, 이산 관측 아시안 콜(산술·기하, $n=50$ 관측일), 다운앤아웃 장벽 콜($H=90$)을 몬테카를로로 가격 결정하고, (i) 반정 변량(antithetic)과 대조 변량(control variate)으로 분산을 얼마나 줄이는지 정량화하며(00b), (ii) 장벽 옵션의 이산화 편향과 연속성 보정(BGK)·브라운 다리 보정을 비교하고(07c의 이산화 오차 관점), (iii) 그릭스(Δ, vega, Γ)를 경로별·우도비 추정량으로 구해 닫힌 형식과 대조한다(07e).

**합격 기준 (이 그림/숫자가 나오면 성공).** (1) 유러피언 콜 MC(200,000 경로, FAST 20,000)가 BS 10.450584와 4 SE 이내; 반정 변량이 분산을 약 2.0배, $S_T$ 대조 변량이 약 6.9배 줄이는 것을 SE로 확인; (2) 기하 아시안 MC가 닫힌 형식 5.641058과 4 SE 이내; 산술 아시안의 대조 변량 추정이 plain보다 SE를 약 35배(분산 1,300배) 줄이고 참고값 $5.8576\pm0.0002$와 일치; (3) 장벽: $m=50$ 이산 관측 MC ≈ 9.18(정확 이산값 9.18212, BGK 9.18224)로 연속 공식 8.665472보다 0.52 높고, 브라운 다리 보정 MC는 8.6655와 4 SE 이내; 편향 vs $m$의 로그-로그 기울기 ≈ $-0.42$(→ $-1/2$); (4) 경로별 Δ = 0.636831, vega = 37.524와 4 SE 이내, 우도비 Γ = 0.018762와 4 SE 이내, 우도비 Δ의 SE가 경로별의 약 2.6배.

**재사용 노트북.** 07e(BS 공식·위험중립·`black_scholes_call`·`mc_option_price`), 07c(오일러–마루야마 vs 정확 GBM 스텝, 약수렴 편향), 00b(SE·log-log 오차), 06c(반사 원리·브라운 다리 교차확률), 06e(`gbm_paths`).

**단계.** Task 1 유러피언 + 분산 감소, Task 2 아시안 + 대조 변량 + EM 편향, Task 3 장벽 + 이산화 편향 + 보정, Task 4 그릭스, Task 5 가격표 보고.

## C5 · 캡스톤 5: 확률적 SIR 전염병 모형 (Capstone 5: Stochastic SIR Epidemics — CTMC, Branching Approximation and Final Size)

- 파일: [C5_stochastic_sir.ipynb](C5_stochastic_sir.ipynb) · 예상 150분 · 선수: 03a, 01g, 02a, 03b, 01c, 05d, 00b, C4

**프로젝트 브리프.** 마르코프 SIR 전염병 모형(인구 $N=1000$, 접촉률 $\beta=2$, 회복률 $\gamma=1$, $R_0=\beta/\gamma=2$, 초기 감염자 $I_0=1$)을 CTMC로 정의하고 Gillespie로 시뮬레이션하여 결정론적 ODE와 대조한다. 핵심 질문 네 가지: (i) 감염자 1명에서 시작하면 얼마나 자주 초기에 사그라지는가(분기 과정 근사 $1/R_0$; 정확값은 최종 규모 DP로), (ii) 대유행이 나면 최종 규모는 얼마인가(최종 규모 방정식 $z = 1-e^{-R_0z}$)와 그 이봉(bimodal) 분포, (iii) 정점 시각은 왜, 얼마나 흩어지는가(초기 단계의 마팅게일 극한 $W$에 의한 시간 이동), (iv) 작은 $N$에서 생성원 행렬로 모든 것을 정확히 계산할 수 있는가(03a/03b/01c).

**합격 기준 (이 그림/숫자가 나오면 성공).** (1) $N=30$: 496상태 생성원 $Q$로 `transition_matrix`가 준 흡수확률(최종 규모 pmf)이 DP와 $10^{-10}$ 이내 일치, $P(I_5=0) = 0.66260$·$E[T_{ext}] = 3.3408$이 Gillespie와 4 SE 이내; (2) $N=1000$: 최종 규모 히스토그램이 이봉(0.502가 $Z\le50$, 나머지가 800 근처)이고 정확 pmf(DP)와 겹침; $P(Z\le100)$ MC가 정확값 0.50207과 4 SE 이내(분기 근사 0.5와의 차이 0.002는 $O(1/N)$); $E[Z\mid\text{major}]$가 795.375와 4 SE 이내(ODE 최종 규모 797); (3) 기하 자손분포($p=1/3$)의 `extinction_probability` = 0.5, 10세대 소멸확률 0.49976이 `galton_watson`과 4 SE 이내; $I_0=3$에서 $P(\text{minor}) = 0.12774 \approx (1/2)^3$; (4) 대유행 조건부 정점 시각의 히스토그램(평균 ≈6.61, sd ≈1.45)이 ODE 정점 6.757 주위에 퍼져 있고 시간 이동 법칙 밀도(평균 6.64, sd 1.28)와 대체로 겹침; (5) $R_0\in\{1.5,2,3\}$에서 $P(\text{minor})$ 정확값(0.6732, 0.5021, 0.3341)이 $1/R_0$과, $E[Z\mid\text{major}]/N$(0.578, 0.795, 0.940)이 $z$(0.583, 0.797, 0.940)와 나란히 그려짐.

**재사용 노트북.** 03a(Gillespie·생성원), 01g(골턴–왓슨·소멸확률·`extinction_probability`), 02a(경쟁하는 시계: 다음 사건이 감염일 확률), 03b(`transition_matrix`=expm), 01c(흡수확률·기본행렬), 05d(마팅게일 극한 $W$), 00b(SE).

**단계.** Task 1 작은 N 정확 계산, Task 2 N=1000 Gillespie와 최종 규모, Task 3 분기 근사, Task 4 정점 시각과 시간 이동 법칙, Task 5 $R_0$ 민감도, Task 6 보고서.
